## 1. 式

**定義（式）.** **式** は正の整数の有限列 $`s = (s_0, \ldots, s_{n-1})`$（$`n \in \mathbb N`$）で、空か、$`s_0 = 1`$ のものである。

- 列の番号は 0 から数える。$`i`$ 番目の項を「列 $`i`$」と呼ぶ。
- **種** は $`(1, m)`$（$`m \ge 2`$ は整数）の形の式である。式は、種から展開（§4）で作れるものでなくてもよい。1-Y 版では $`m \ge 1`$ である。
- 式の順序は辞書式順序 $`\lt_{\mathrm{lex}}`$ である。真の接頭辞は小さい。[02](02-well-founded.md) §1 のとおり、この順序は式全体の上では整礎でない。

## 2. 行

ω-Y の山の行は、自然数ではなく $`\omega^\omega`$ より小さい順序数である。この節は 1-Y 版に無い。

**定義（行）.** **行** は $`\omega^\omega`$ より小さい順序数である。行 $`a`$ を Cantor の標準形で次のように書き、$`c_i(a)`$ を $`a`$ の **係数** と呼ぶ（$`i \gt d`$ では $`c_i(a) = 0`$）。

```math
a = \omega^{d} c_d(a) + \cdots + \omega^{2} c_2(a) + \omega\, c_1(a) + c_0(a)
```

行の順序は順序数の順序である。係数で書くと、次のとおりである。

```math
a \lt b \iff \exists i\ \bigl(c_i(a) \lt c_i(b) \ \wedge\ \forall j \gt i\ \ c_j(a) = c_j(b)\bigr)
```

| 行 | 係数の列 $`(c_0, c_1, c_2)`$ |
|---|---|
| $`1`$ | $`(1, 0, 0)`$ |
| $`2`$ | $`(2, 0, 0)`$ |
| $`\omega`$ | $`(0, 1, 0)`$ |
| $`\omega + 1`$ | $`(1, 1, 0)`$ |
| $`\omega \cdot 2`$ | $`(0, 2, 0)`$ |
| $`\omega^2`$ | $`(0, 0, 1)`$ |

**定義（跳び）.** 2 つの行 $`a, b`$ の **跳び** を次で定める。

```math
\mathrm{jump}(a, b) = \begin{cases} 0 & (a = b) \cr 1 + \max\{\, i \mid c_i(a) \ne c_i(b) \,\} & (a \ne b) \end{cases}
```

**定義（ω の冪を足す）.** 行 $`a`$ と自然数 $`e`$ について、$`a + \omega^e`$ は順序数の和である。係数で書くと、次のとおりである。

```math
c_i(a + \omega^e) = \begin{cases} 0 & (i \lt e) \cr c_e(a) + 1 & (i = e) \cr c_i(a) & (i \gt e) \end{cases}
```

$`a \lt a + \omega^e`$ で、$`\mathrm{jump}(a, a + \omega^e) = e + 1`$ である。

**定義（次の行）.** $`B(a, b) := a + \omega^{\mathrm{jump}(a, b)}`$ とする。

| $`a`$ | $`b`$ | $`\mathrm{jump}(a, b)`$ | $`B(a, b)`$ |
|---|---|---|---|
| $`1`$ | $`1`$ | $`0`$ | $`2`$ |
| $`2`$ | $`2`$ | $`0`$ | $`3`$ |
| $`2`$ | $`1`$ | $`1`$ | $`2 + \omega = \omega`$ |
| $`\omega`$ | $`1`$ | $`2`$ | $`\omega + \omega^2 = \omega^2`$ |
| $`\omega`$ | $`\omega`$ | $`0`$ | $`\omega + 1`$ |
| $`\omega + 1`$ | $`\omega`$ | $`1`$ | $`\omega \cdot 2`$ |

$`a = b`$ なら $`B(a, b) = a + 1`$ で、行は 1 つ上がる。これは 1-Y 数列（[01](01-ordinals.md) §7 の 1-Y 版が扱う数列）の山の行の動きと同じである。$`a \ne b`$ なら、行は $`\omega`$ の冪だけ跳ぶ。

**定義（層）.** 1 以上の行 $`a`$ の **層** を $`\mathrm{lay}(a) := \max\{\, i \mid c_i(a) \ne 0 \,\}`$ とする。$`\mathrm{lay}(a) = k`$ と $`\omega^k \le a \lt \omega^{k+1}`$ は同じことである。

## 3. 山

式 $`s`$ から、列ごとに、行の有限集合と、各行の値と親を作る。この表を $`s`$ の **山** $`M(s)`$ と呼ぶ。列 $`c`$ の行の集合を $`\mathrm{rows}(c)`$ と書く。これは 0 と 1 を含む行の有限集合である。列 $`c`$ の行 $`a \in \mathrm{rows}(c)`$ の値を $`v_a(c)`$、親を $`\mathrm{par}_a(c)`$ と書く。

- 組 $`(c, a)`$（$`a \in \mathrm{rows}(c)`$）を **節点** と呼ぶ。節点 $`u = (c, a)`$ について $`\mathrm{col}(u) := c`$、$`\mathrm{row}(u) := a`$、$`v(u) := v_a(c)`$ と書く。
- 行 0 の節点 $`(c, 0)`$ を **phantom**（仮の節点）と呼ぶ。行 1 の節点を **最下の節点** と呼ぶ。行 1 が 1-Y の行 0 に当たる。
- 列 $`c`$ の中で、$`a^{+} := \min\{\, b \in \mathrm{rows}(c) \mid b \gt a \,\}`$ を $`a`$ の真上の行、$`a^{-} := \max\{\, b \in \mathrm{rows}(c) \mid b \lt a \,\}`$ を真下の行と呼ぶ。$`\mathrm{top}(c) := \max \mathrm{rows}(c)`$ を一番上の行と呼ぶ。
- 行 $`a \lt \mathrm{top}(c)`$ の親 $`\mathrm{par}_a(c)`$ は、左の列の節点である。行 $`b \ge 1`$ の節点の **左の脚** を $`\lambda(c, b) := \mathrm{par}_{b^{-}}(c)`$ とする（$`(c, b) \ne (0, 1)`$）。

**定義（山）.** 列 $`c = 0, 1, \ldots`$ の順に、次の式で $`\mathrm{rows}(c)`$ と値と親を決める。

- 行 0：$`v_0(c) := 0`$。$`c \ge 1`$ なら $`\mathrm{par}_0(c) := (c - 1, 0)`$。
- 行 1：$`v_1(c) := s_c`$。
- 行 $`a \ge 1`$ で $`v_a(c) \gt 1`$ なら、親 $`\pi := \mathrm{par}_a(c)`$ を下の「親の探し方」で決め、次の行と値を次で定める。

```math
a^{+} := B(a, \mathrm{row}(\pi)), \qquad v_{a^{+}}(c) := v_a(c) - v(\pi)
```

- $`\mathrm{rows}(c)`$ は、行 0、行 1 と、この規則で作った行からなる。$`v_a(c) = 1`$ となった行 $`a`$ が $`\mathrm{top}(c)`$ で、そこには親が無い。

2 つめの式は、1-Y の「差」$`v_{r+1}(c) = v_r(c) - v_r(p)`$ と同じ形である。値は上へ行くほど真に減るので、$`\mathrm{rows}(c)`$ は有限である。

**定義（親の探し方）.** 行 $`b \ge 1`$ の節点 $`\nu = (c', b)`$ について、$`\lambda(\nu) = (p, e)`$ として次のように定める。

```math
\mathrm{next}(\nu) := \bigl(p,\ \max(\{e\} \cup \{\, a \in \mathrm{rows}(p) \mid a \le b \,\})\bigr)
```

$`\nu`$ の左の脚から、列 $`p`$ の中を、行 $`b`$ 以下の範囲で一番上まで登った節点である。$`v_a(c) \gt 1`$ の節点 $`u = (c, a)`$ の親を次で定める。

```math
\mathrm{par}_a(c) := \mathrm{next}^{j}(u), \qquad j := \min\{\, j \ge 1 \mid 0 \lt v(\mathrm{next}^{j}(u)) \lt v_a(c) \,\}
```

これは 1-Y の「行 $`r+1`$ の親」（祖先 $`p`$ のうち $`0 \lt v(p) \lt v(c)`$ を満たす最大のもの）と同じ形である。祖先を右から順にたどり、最初に条件を満たすものを取る。ω-Y では、たどる列が左の脚と登り方で決まる。

$`j`$ は必ずある。$`\mathrm{next}`$ は列の番号を真に減らし、行は 1 以上のままである。列 0 に着くと、その節点は $`(0, 1)`$ で、$`v(0, 1) = s_0 = 1 \lt v_a(c)`$ だからである。

**性質（行 1 の親）.** $`s_c \gt 1`$ のとき、$`\mathrm{par}_1(c) = (p, 1)`$ である。ここで $`p`$ は、$`p \lt c`$ かつ $`s_p \lt s_c`$ を満たす最大の $`p`$ である。これは 1-Y の行 0 の親（1-Y 版 §2）と同じである。

証明. $`\lambda(c', 1) = (c' - 1, 0)`$ で、$`\mathrm{rows}(c' - 1)`$ の 1 以下の最大の行は 1 である。よって $`\mathrm{next}(c', 1) = (c' - 1, 1)`$ である。$`(c, 1)`$ から $`\mathrm{next}`$ をくり返すと、$`(c-1, 1), (c-2, 1), \ldots`$ を順にたどる。値は $`s_{c-1}, s_{c-2}, \ldots`$ で、どれも 0 より大きい。∎

**定義（辺）.** 行 $`1 \le a \lt \mathrm{top}(c)`$ について、節点 $`(c, a)`$ から $`(c, a^{+})`$ への **親子の辺**（または単に **辺**）がある。$`(c, a)`$ を辺の **下の節点**、$`(c, a^{+})`$ を **上の節点**、$`\mathrm{par}_a(c)`$ を辺の **親** と呼ぶ。親はいつも左の列にある。

- 辺の **次数** を $`\delta_c(a) := \mathrm{jump}(a, \mathrm{row}(\mathrm{par}_a(c)))`$ とする。$`a^{+} = a + \omega^{\delta_c(a)}`$ である。行 0 でも $`\delta_c(0) := 0`$ とする（$`0^{+} = 1 = 0 + \omega^0`$）。
- 辺の **層** を、上の節点の行の層 $`\mathrm{lay}(a^{+})`$ とする。
- phantom から最下の節点への段は辺と呼ばない。

**例（$`(1, 4, 20)`$）.** 表の「$`v \leftarrow (p, e)`$」は、値が $`v`$ で、左の脚（下の辺の親）が節点 $`(p, e)`$ であることを表す。最下の節点の左の脚（左の列の phantom）は書かない。ω-Y の山には 1-Y のような層の積み重ねは無く、全体が 1 枚の表になる。

| 行 | 列 0 | 列 1 | 列 2 |
|---|---|---|---|
| $`\omega^2 \cdot 2`$ | | | $`1 \leftarrow (1, \omega^2)`$ |
| $`\omega^2 + \omega`$ | | | $`2 \leftarrow (1, \omega^2)`$ |
| $`\omega^2 + 1`$ | | | $`3 \leftarrow (1, \omega^2)`$ |
| $`\omega^2`$ | | $`1 \leftarrow (0, 1)`$ | $`4 \leftarrow (1, \omega)`$ |
| $`\omega \cdot 2`$ | | | $`6 \leftarrow (1, \omega)`$ |
| $`\omega + 1`$ | | | $`8 \leftarrow (1, \omega)`$ |
| $`\omega`$ | | $`2 \leftarrow (0, 1)`$ | $`10 \leftarrow (1, 2)`$ |
| $`3`$ | | | $`13 \leftarrow (1, 2)`$ |
| $`2`$ | | $`3 \leftarrow (0, 1)`$ | $`16 \leftarrow (1, 1)`$ |
| $`1`$ | $`1`$ | $`4`$ | $`20`$ |
| $`0`$ | phantom | phantom | phantom |

- 列 0：$`v_1(0) = 1`$ なので、$`\mathrm{rows}(0) = \{0, 1\}`$ である。
- 列 1：$`\mathrm{par}_1(1) = (0, 1)`$（値 $`1 \lt 4`$）で、$`2 = B(1, 1)`$、値 $`4 - 1 = 3`$。行 2 では $`\mathrm{next}(1, 2) = (0, \max(\{1\} \cup \{0, 1\})) = (0, 1)`$ で、親はまた $`(0, 1)`$ である。$`B(2, 1) = 2 + \omega = \omega`$（跳び 1）、値 2。同じく $`B(\omega, 1) = \omega + \omega^2 = \omega^2`$（跳び 2）、値 1 で終わる。
- 列 2：どの節点でも $`j = 1`$、つまり $`\mathrm{next}(u)`$ がそのまま親になる。次の表は、下の節点から順に、$`\mathrm{next}(u)`$ と次の行と値を書いたものである。

| 節点 $`u`$（行、値） | $`\lambda(u)`$ | $`\mathrm{next}(u)`$ とその値 | 次の行 $`B`$ | 次の値 |
|---|---|---|---|---|
| $`1`$、20 | $`(1, 0)`$ | $`(1, 1)`$、4 | $`B(1, 1) = 2`$（跳び 0） | $`20 - 4 = 16`$ |
| $`2`$、16 | $`(1, 1)`$ | $`(1, 2)`$、3（行 $`\omega \gt 2`$ へは登らない） | $`B(2, 2) = 3`$（跳び 0） | $`16 - 3 = 13`$ |
| $`3`$、13 | $`(1, 2)`$ | $`(1, 2)`$、3 | $`B(3, 2) = 3 + \omega = \omega`$（跳び 1） | $`13 - 3 = 10`$ |
| $`\omega`$、10 | $`(1, 2)`$ | $`(1, \omega)`$、2 | $`B(\omega, \omega) = \omega + 1`$（跳び 0） | $`10 - 2 = 8`$ |
| $`\omega + 1`$、8 | $`(1, \omega)`$ | $`(1, \omega)`$、2 | $`B(\omega + 1, \omega) = \omega \cdot 2`$（跳び 1） | $`8 - 2 = 6`$ |
| $`\omega \cdot 2`$、6 | $`(1, \omega)`$ | $`(1, \omega)`$、2 | $`B(\omega \cdot 2, \omega) = \omega^2`$（跳び 2） | $`6 - 2 = 4`$ |
| $`\omega^2`$、4 | $`(1, \omega)`$ | $`(1, \omega^2)`$、1 | $`B(\omega^2, \omega^2) = \omega^2 + 1`$（跳び 0） | $`4 - 1 = 3`$ |
| $`\omega^2 + 1`$、3 | $`(1, \omega^2)`$ | $`(1, \omega^2)`$、1 | $`B(\omega^2 + 1, \omega^2) = \omega^2 + \omega`$（跳び 1） | $`3 - 1 = 2`$ |
| $`\omega^2 + \omega`$、2 | $`(1, \omega^2)`$ | $`(1, \omega^2)`$、1 | $`B(\omega^2 + \omega, \omega^2) = \omega^2 \cdot 2`$（跳び 2） | $`2 - 1 = 1`$ |

列 2 の親は、列 1 の節点を下から順にたどる。親が変わった最初の節点は親と同じ行にあり、跳びは 0 である。その後、同じ親の間は跳びが 1、2 と大きくなる。新しい行が列 1 の次の節点の行に届くと（行 $`\omega`$ と $`\omega^2`$）、$`\mathrm{next}`$ はその節点へ登り、親が変わる。

列 1 の辺は、下から行 2、$`\omega`$、$`\omega^2`$ へ上がるので、層は 0、1、2 である。

**1-Y の山との対応.** 1-Y の山（1-Y 版 §2〜§4）は、層 $`0, 1, 2, \ldots`$ の山を積んだものである。層 $`k`$ の頂上の値は、層 $`k + 1`$ の行 0 の値である。そこで 1-Y の列 $`c`$ の値を、層 0 の行 0 から頂上まで、続けて層 1 の行 1 から頂上まで、続けて層 2 の行 1 から頂上まで、…の順に 1 本に並べる（層 $`k`$ の頂上と層 $`k + 1`$ の行 0 は 1 つに数える）。並びの隣どうしは、1-Y の親子の辺でつながる。計算機で調べた範囲では、次の 2 つが成り立った。

1. $`M(s)`$ の列 $`c`$ の値 $`v_a(c)`$（$`a \ge 1`$）を下から読むと、1-Y の列 $`c`$ の並びと同じになる。
2. 1-Y の層 $`k`$、行 $`r`$ の辺で、親が列 $`p`$ のものに当たる $`M(s)`$ の辺は、層が $`k`$ である。その辺の親は列 $`p`$ の節点で、列 $`p`$ の並びで同じ位置（層 $`k`$、行 $`r`$）にある。

つまりこの範囲では、ω-Y の山は 1-Y の層を列ごとに 1 本につないだもので、辺の層が 1-Y の層を表す。1-Y の列 $`c`$ の層 $`k`$ での高さ $`h_k(c)`$ は、$`M(s)`$ の列 $`c`$ の層 $`k`$ の辺の数である。

調べた範囲は、種 $`(1, 2)`$、$`(1, 3)`$、$`(1, 4)`$ から、1-Y の展開（$`N = 1, 2, 3`$）と接頭辞を取ることをくり返して届く長さ 6 以下の式のうち、最後の項が 1 でないもの 40850 個である（2026-09-26）。これらの山で $`\omega^2`$ 以上の行を持つのは $`(1, 4)`$ だけである。この範囲の外では成り立たないことがある。種 $`(1, 5)`$ から 1-Y で届く $`(1, 4, 15)`$ では、値と親は同じだが、列 2 の一番上の辺は、1-Y では層 2、ω-Y では行 $`\omega \cdot 2`$ への辺で層 1 である。$`(1, 4, 16)`$ では、列 2 の一番上の辺の親が、1-Y では列 1、ω-Y では列 0 で、親も違う。どちらの山にも $`\omega^2`$ 以上の行がある。これは証明ではなく、Lean でも示していない。

## 4. 展開

**定義（根）.** 最後の列を $`x := n - 1`$ とする。ある行 $`a`$ で、$`x`$ が親 $`\pi = \mathrm{par}_a(x)`$ を持ち、$`v_a(x) = v(\pi) + 1`$ となるとき、$`\pi`$ を **根** と呼ぶ。

- そのような $`a`$ は高々 1 つで、$`a^{+} = \mathrm{top}(x)`$ である。$`v_{a^{+}}(x) = v_a(x) - v(\pi) = 1`$ で、値 1 の行は一番上だけだからである。つまり根は、列 $`x`$ の一番上の辺の親である。
- $`s_x \gt 1`$ なら根はある（列 $`x`$ に辺があり、一番上の辺が条件を満たす）。$`s_x = 1`$ なら列 $`x`$ に辺が無く、根は無い。
- 根を $`(z, d)`$ と書く。$`z`$ を根の列、$`d`$ を根の行と呼ぶ。$`K := \mathrm{lay}(\mathrm{top}(x))`$ を **根の層** と呼ぶ（一番上の辺の層）。

1-Y の悪い根（1-Y 版 §5）も同じ式 $`v(x) = v(p) + 1`$ で定義される。下の表の式では、根の列と根の層は、1-Y の悪い根の列と層に等しい。

| 式 | 根 $`(z, d)`$ | $`\mathrm{top}(x)`$ | 根の層 $`K`$ | 1-Y の悪い根の（層、行、列） |
|---|---|---|---|---|
| $`(1, 2, 3)`$ | $`(1, 1)`$ | $`2`$ | 0 | $`(0, 0, 1)`$ |
| $`(1, 2, 4)`$ | $`(1, 2)`$ | $`3`$ | 0 | $`(0, 1, 1)`$ |
| $`(1, 3)`$ | $`(0, 1)`$ | $`\omega`$ | 1 | $`(1, 0, 0)`$ |
| $`(1, 2, 4, 3)`$ | $`(1, 1)`$ | $`2`$ | 0 | $`(0, 0, 1)`$ |

**定義（展開 $`s[N]`$）.** $`N \in \mathbb N`$ はコピーの回数である。最後の列を $`x`$ とする。

- (0) 根が無いとき（$`s`$ が空か $`s_x = 1`$）：最後の列を消す。$`s[N] = (s_0, \ldots, s_{x-1})`$。空の式では $`s[N] = ()`$ である。
- 根 $`(z, d)`$ があるとき：$`L := x - z`$ とし、長さ $`W := x + N L`$ の式 $`s[N]`$ を、下の手順 1、2 で作る。値をそのまま写すのではなく、山を写し、そこから値を組み立て直す。$`N = 0`$ なら $`W = x`$ で、$`s[0] = (s_0, \ldots, s_{x-1})`$ になる。

**定義（ブロック）.** 根 $`(z, d)`$ があるとき、$`i = 0, 1, \ldots, N`$ について、$`s[N]`$ の列 $`z + i L`$ から $`z + (i+1) L - 1`$ までを **ブロック $`i`$** と呼ぶ。ブロック 0 はもとの列 $`z, \ldots, x - 1`$ で、ブロック $`1, \ldots, N`$ がそのコピーである。列 $`z`$ 以上の列は、ただ 1 通りに $`c = z + i L + j`$（$`0 \le i \le N`$、$`0 \le j \lt L`$）と書ける。$`i`$ をブロックの番号、$`j`$ をブロックの中の位置と呼ぶ。例えば $`(1, 2, 2)[2] = (1, 2, 1, 2, 1, 2)`$ では $`z = 0`$、$`x = 2`$ で、ブロック 0、1、2 は列 $`\{0, 1\}`$、$`\{2, 3\}`$、$`\{4, 5\}`$ である。

**定義（写す元の列）.** 列 $`c = z + i L + j \ge x`$ について、写す元の列 $`\sigma`$ とずらす回数 $`b`$ を次で決める。$`j \ge 1`$ なら $`\sigma := z + j`$、$`b := i`$。$`j = 0`$ なら $`\sigma := x`$、$`b := i - 1`$。$`c = \sigma + b L`$ である。列 $`c = x`$ は $`\sigma = x`$、$`b = 0`$ である。1-Y 版では、この $`\sigma, b`$ を §6 の枝 (3-2) だけで使う。ω-Y では、すべての層で使う。

**定義（ずらし）.** $`i \in \mathbb N`$ と列 $`p`$ について、$`p \lt z`$ なら $`m_i(p) := p`$、$`p \ge z`$ なら $`m_i(p) := p + i L`$ とする。ブロック 0 の列を、ブロック $`i`$ の同じ位置へ移す写像である。

以下、ω-Y だけの定義が続く。

**定義（減一の山）.** $`s' := (s_0, \ldots, s_{x-1}, s_x - 1)`$ とする。$`M(s')`$ の行の集合、値、親、左の脚、次数、一番上の行を $`\widetilde{\mathrm{rows}}(c)`$、$`\tilde v_a(c)`$、$`\widetilde{\mathrm{par}}_a(c)`$、$`\tilde\lambda(c, a)`$、$`\tilde\delta_c(a)`$、$`\widetilde{\mathrm{top}}(c)`$ と書く。節点 $`u = (c, a)`$ については $`\widetilde{\mathrm{par}}(u) := \widetilde{\mathrm{par}}_a(c)`$ と書く。列 $`c \lt x`$ の山は $`s_0, \ldots, s_c`$ だけで決まるので、$`M(s')`$ と $`M(s)`$ で同じである。特に根 $`(z, d)`$ は $`M(s')`$ の節点でもある。

**注（列 $`x`$）.** $`M(s)`$ の列 $`x`$ の行を $`0 = a_0 \lt 1 = a_1 \lt \cdots \lt a_T = \mathrm{top}(x)`$ とする。$`1 \le k \le T - 1`$ で、$`a_k \in \widetilde{\mathrm{rows}}(x)`$、$`\tilde\lambda(x, a_k) = \lambda(x, a_k)`$、$`\tilde v_{a_k}(x) = v_{a_k}(x) - 1`$ である。つまり $`M(s)`$ の列 $`x`$ の一番上の辺より下の辺は、$`M(s')`$ でも同じである。

証明. $`k`$ についての帰納法で示す。$`k = 1`$ では、どちらも行 1 で、左の脚は $`(x - 1, 0)`$、値は $`s_x`$ と $`s_x - 1`$ である。$`k \le T - 2`$ とする。$`a_{k+1}`$ は一番上でないので $`v_{a_{k+1}}(x) \ge 2`$ である。よって $`\pi_k := \mathrm{par}_{a_k}(x)`$ について $`v(\pi_k) = v_{a_k}(x) - v_{a_{k+1}}(x) \le v_{a_k}(x) - 2`$ で、$`\tilde v_{a_k}(x) = v_{a_k}(x) - 1 \ge 2`$ である。だから $`M(s')`$ でも行 $`a_k`$ の親を探す。$`\mathrm{next}`$ は今の節点の行と左の脚と列 $`x`$ より左の列で決まるので、$`\mathrm{next}^j(x, a_k)`$ の列は $`M(s)`$ と $`M(s')`$ で同じである。$`M(s)`$ で退けた節点は、値が 0 か $`v_{a_k}(x)`$ 以上なので、$`\tilde v_{a_k}(x)`$ に対しても退けられる。$`\pi_k`$ は $`0 \lt v(\pi_k) \lt \tilde v_{a_k}(x)`$ なので、$`M(s')`$ でも親になる。よって $`\widetilde{\mathrm{par}}_{a_k}(x) = \pi_k`$、真上の行は同じ $`a_{k+1}`$、値は $`\tilde v_{a_{k+1}}(x) = v_{a_{k+1}}(x) - 1`$ である。$`k = T - 1`$ では $`\pi_{T-1}`$ は根で、$`v(\pi_{T-1}) = v_{a_{T-1}}(x) - 1 = \tilde v_{a_{T-1}}(x)`$ なので、$`M(s')`$ では親にならない。ここから上は $`M(s)`$ と違ってよい。∎

**定義（境界の行）.** $`\Gamma := \{\mathrm{top}(x)\} \cup \{\, a \in \mathrm{rows}(z) \mid 1 \le a \le d \,\}`$ とする。列 $`x`$ の一番上の行と、根の列の根以下の行（phantom を除く）である。

**定義（marker）.** $`M(s')`$ の節点 $`\mu = (c, a)`$（$`a \lt \widetilde{\mathrm{top}}(c)`$）が **marker** であるとは、次を満たすことをいう。

```math
z \lt c \le x \ \wedge\ a \le d \ \wedge\ \exists m \ge 1\ \Bigl(\mathrm{col}\bigl(\widetilde{\mathrm{par}}^{m}(\mu)\bigr) = z \ \wedge\ \forall i \in \{1, \ldots, m\}\ \ \mathrm{row}\bigl(\widetilde{\mathrm{par}}^{i}(\mu)\bigr) = a\Bigr)
```

親を同じ行のままたどって、根の列の根以下の節点 $`(z, a)`$ に着く節点である。marker の集合を $`\mathrm{Mk}`$、列 $`\sigma`$ の marker の集合を $`\mathrm{Mk}(\sigma)`$ と書く。

- $`z \lt c \le x`$ の phantom $`(c, 0)`$ はどれも marker である（$`\widetilde{\mathrm{par}}_0(c) = (c - 1, 0)`$）。
- marker $`\mu`$ の親 $`\widetilde{\mathrm{par}}(\mu)`$ は、marker か列 $`z`$ の節点である。よって $`\mathrm{col}(\widetilde{\mathrm{par}}(\mu)) \ge z`$ である。

**定義（参照の行）.** $`b \ge 1`$ のとき、列 $`x + (b - 1) L`$（$`b = 1`$ では $`M(s')`$ の列 $`x`$、$`b \ge 2`$ ではブロック $`b`$ の最初の列 $`z + bL`$）を使って、次のように定める。

```math
\beta_b(\gamma) := \max\{\, e \in \mathrm{rows}'(x + (b - 1) L) \mid e \lt \gamma \,\} \quad (\gamma \in \Gamma), \qquad g_b(a) := \min\{\, \beta_b(\gamma) \mid \gamma \in \Gamma,\ \beta_b(\gamma) \ge a \,\}
```

$`\mathrm{rows}'`$ は下の手順 1 で作る新しい山の行の集合である。列 $`x + (b-1)L`$ は列 $`c = \sigma + bL \gt x`$ より左なので、先に決まっている。

**定義（左の脚の写し）.** 節点 $`\nu`$ と行 $`\gamma`$ について、次のように定める。

```math
\mathrm{tr}_b(\nu, \gamma) := \begin{cases} \nu & (\mathrm{col}(\nu) \lt z) \cr \bigl(m_b(\mathrm{col}(\nu)),\ \max\{\, e \in \mathrm{rows}'(m_b(\mathrm{col}(\nu))) \mid e \lt \gamma \,\}\bigr) & (\mathrm{col}(\nu) \ge z) \end{cases}
```

根の列より左の節点はそのまま使う。そうでなければ、ずらした列の、行 $`\gamma`$ より下の最も高い節点を使う。

**手順 1（山を写す）.** $`s[N]`$ の列 $`c \lt W`$ の行の集合 $`\mathrm{rows}'(c)`$ と、行 $`e \ge 1`$ の左の脚 $`\lambda'(c, e)`$ を、$`c`$ の小さい順に決める。親は §3 と同じく $`\mathrm{par}'_a(c) := \lambda'(c, a^{+})`$ で、$`a^{+}`$ は $`\mathrm{rows}'(c)`$ での真上の行である。

- 列 $`c \le x`$：$`M(s')`$ の列 $`c`$ のまま。$`\mathrm{rows}'(c) := \widetilde{\mathrm{rows}}(c)`$、$`\lambda'(c, e) := \tilde\lambda(c, e)`$。$`c \lt x`$ では $`M(s)`$ のままでもある。
- 列 $`c \gt x`$（$`c = \sigma + bL`$、$`b \ge 1`$）：$`\mathrm{Mk}(\sigma)`$ の marker $`\mu = (\sigma, a)`$ ごとに、次の 3 種類の節点を置く。$`\mathrm{rows}'(c)`$ は、置いた節点の行の全体である。
  - **(T) 平行移動**：行 $`a`$ に節点を置く。$`a \ge 1`$ なら $`\lambda'(c, a) := \mathrm{tr}_b(\tilde\lambda(\sigma, a), a)`$。
  - **(C) 輪郭**：$`\mu`$ から上の $`M(s')`$ の列 $`\sigma`$ の行を $`a_0 := a`$、$`a_{t+1} := a_t^{+}`$ とする。$`t_\mu := \min\{\, t \ge 0 \mid a_t = \widetilde{\mathrm{top}}(\sigma) \ \vee\ (\sigma, a_{t+1}) \in \mathrm{Mk} \,\}`$ とする。行 $`\gamma_0 := g_b(a)`$、$`\gamma_{t+1} := \gamma_t + \omega^{\tilde\delta_\sigma(a_t)}`$ を定め、$`1 \le t \le t_\mu`$ について行 $`\gamma_t`$ に節点を置く。$`\lambda'(c, \gamma_t) := \mathrm{tr}_b(\tilde\lambda(\sigma, a_t), \gamma_t)`$。
  - **(F) 充填**：$`p := \widetilde{\mathrm{par}}(\mu)`$ とする。行 $`e_q \in \mathrm{rows}'(m_b(\mathrm{col}(p)))`$ で $`a \le e_q \lt g_b(a)`$ のものごとに、$`q := (m_b(\mathrm{col}(p)), e_q)`$ とし、$`0 \le i \le \delta'(q)`$ について行 $`e_q + \omega^{i}`$ に節点を置く。$`\lambda'(c, e_q + \omega^{i}) := q`$。ここで $`\delta'(q)`$ は新しい山での $`q`$ の次数で、$`e_q^{+} = e_q + \omega^{\delta'(q)}`$ である。

式ならば、$`g_b(a)`$ の集合は空でなく、手順 1 で 1 つの列に置く節点の行はどれも違う（Lean で示してある。§9）。

**定義（源の節点、すき間の節点）.** (T) で置いた節点 $`(c, a)`$ の **源の節点** は $`(\sigma, a)`$、(C) で置いた節点 $`(c, \gamma_t)`$ の源の節点は $`(\sigma, a_t)`$ である。新しい辺の上の節点に源の節点 $`(\sigma, a_s)`$ があるとき、$`(\sigma, a_s)`$ を上の節点とする $`M(s')`$ の辺を、その辺の **源の辺** と呼ぶ。(F) で置いた節点を **すき間の節点** と呼ぶ。列 $`c \le x`$ の節点の源の節点は、その節点自身とする。

**手順 2（値を組み立て直す）.** 各列 $`c \lt W`$ について、$`\mathrm{top}'(c) := \max \mathrm{rows}'(c)`$ とし、次で値を決める。

```math
v'_a(c) := 1 + \sum_{e \in \mathrm{rows}'(c),\ a \le e \lt \mathrm{top}'(c)} v'(\mathrm{par}'_e(c)) \qquad (1 \le a \le \mathrm{top}'(c))
```

親は左の列なので、この式は左の列から順に決まる。最後に $`s[N] := (v'_1(0), \ldots, v'_1(W - 1))`$ とする。

この式は §3 の差 $`v_{a^{+}}(c) = v_a(c) - v(\mathrm{par}_a(c))`$ を逆にたどったものである。一番上の値が 1 で、1 行下がるたびに親の値を足す。1-Y 版 §6 の手順 2 の式で、頂上の値を $`t_k(c) = 1`$ とし、層を 1 つにしたものである。列 $`c \le x`$ では、$`M(s')`$ の値がそのまま出る。

### 分岐の木

手順 1 で $`s[N]`$ の山にできる辺を、次の枝に分ける。枝の番号は、1-Y 版 §6 の手順 1 の枝の番号と同じにした。番号が同じ枝は、調べた範囲で、1-Y の同じ枝と同じ辺を作る（下の「1-Y の展開との対応」）。(4) は 1-Y に無い枝である。枝は辺の置き方を変えない。手順 1 で置いた辺に番号を付けるだけである。

記号を決める。辺を、上の節点 $`(c, a^{+})`$ で表す。$`\ell := \mathrm{lay}(a^{+})`$ を辺の層とする。上の節点に源の節点があるとき、それを $`(\sigma, a_s)`$ と書く（(T) では $`a_s = a`$、(C) では $`a_s = a_t`$）。$`a^{+} = a_s`$ となる辺を **同じ行に写した辺** と呼ぶ。(T) の辺と列 $`x`$ の辺はいつもそうである。列 $`c`$ の層 $`\ell`$ のすき間の節点の行の集合を $`F_\ell(c) := \{\, e \in \mathrm{rows}'(c) \mid (c, e) \text{ はすき間の節点},\ \mathrm{lay}(e) = \ell \,\}`$ とする。

各枝の頭の番号（(2-3-1) など）で枝を呼ぶ。下の例では、辺ができる枝の番号を「通る分岐」として書く。「もとのまま」の枝 (1-1)、(2-1)、(3-1) は書かない。「もとのまま」は、$`\mathrm{rows}'(c) = \mathrm{rows}(c)`$、$`\lambda'(c, e) = \lambda(c, e)`$ のことである。

- **(0)** 根が無いとき：最後の列を消す（上の定義）。
- **(1) 層 $`\ell \gt K`$（根より上）**
  - (1-1) $`c \lt x`$：もとのまま。
  - (1-2) $`c \ge x`$ で同じ行に写した辺：上の節点の行は $`a_s`$、親は $`\mathrm{tr}_b(\tilde\lambda(\sigma, a_s), a_s)`$（$`c = x`$ では $`\tilde\lambda(x, a_s)`$）。
- **(2) 層 $`\ell = K`$（根の層）**
  - (2-1) $`c \lt x`$：もとのまま。
  - (2-2) $`c \gt x`$、$`j \ge 1`$（$`\sigma \lt x`$）で同じ行に写した辺：上の節点の行は $`a_s`$、親は $`\mathrm{tr}_b(\tilde\lambda(\sigma, a_s), a_s)`$。
  - (2-3) $`c \ge x`$、$`j = 0`$（$`\sigma = x`$、ブロックの最初の列）で同じ行に写した辺：上の節点の行は $`a_s`$。$`\nu := \tilde\lambda(x, a_s)`$ とする。親は $`\nu`$ の列で分かれる。
    - (2-3-1) $`\mathrm{col}(\nu) \ge z`$：親は $`\bigl(m_b(\mathrm{col}(\nu)),\ \max\{\, e \in \mathrm{rows}'(m_b(\mathrm{col}(\nu))) \mid e \lt a_s \,\}\bigr)`$（$`c = x`$ では $`\nu`$）。
    - (2-3-2) $`\mathrm{col}(\nu) \lt z`$：親は $`\nu`$ そのもの。
- **(3) 層 $`\ell \lt K`$（根より下）**
  - (3-1) $`c \lt x`$：もとのまま。
  - (3-2) $`c \ge x`$。$`c = x`$ の層 $`\lt K`$ の辺は $`M(s)`$ と同じで、もとのままである（注（列 $`x`$）。調べた範囲では、$`M(s')`$ の列 $`x`$ の層 $`\lt K`$ の辺は、どれも $`M(s)`$ の列 $`x`$ の一番上の辺より下にあった）。$`c \gt x`$ の辺は次のとおり。
    - (3-2-1) $`F_\ell(c) \ne \emptyset`$：
      - (3-2-1-1) 上の節点が (T)：上の節点の行は $`a`$、親は $`\mathrm{tr}_b(\tilde\lambda(\sigma, a), a)`$。
      - (3-2-1-2) 上の節点が (F) で $`i = 0`$：上の節点の行は $`e_q + 1`$、親は $`q`$。
      - (3-2-1-3) 上の節点が (C) で、同じ行に写していず、$`\mathrm{lay}(a_t) = \ell`$：上の節点の行は $`\gamma_t`$、親は $`\mathrm{tr}_b(\tilde\lambda(\sigma, a_t), \gamma_t)`$。
    - (3-2-2) $`F_\ell(c) = \emptyset`$ で同じ行に写した辺：上の節点の行は $`a_s`$、親は $`\mathrm{tr}_b(\tilde\lambda(\sigma, a_s), a_s)`$。
- **(4) 1-Y に無い枝**
  - (4-1) 上の節点が (F) で $`i \ge 1`$：上の節点の行は $`e_q + \omega^{i}`$、親は $`q`$。
  - (4-2) 上の節点が (C) で、同じ行に写していず、$`\mathrm{lay}(a_t) \ne \ell`$：上の節点の行は $`\gamma_t`$、親は $`\mathrm{tr}_b(\tilde\lambda(\sigma, a_t), \gamma_t)`$。
  - (4-3) (1)〜(3)、(4-1)、(4-2) のどれにも当たらない辺。次の 3 つである。上の節点が (F) で $`i = 0`$、$`\ell \ge K`$ のもの。上の節点が (C) で、同じ行に写していず、$`\mathrm{lay}(a_t) = \ell`$ で、$`\ell \ge K`$ か $`F_\ell(c) = \emptyset`$ のもの。上の節点が (C) で、同じ行に写し、$`\ell \lt K`$ で $`F_\ell(c) \ne \emptyset`$ のもの。

**例 1（$`(1)[2]`$）.** 根が無い例である。最後の列は $`x = 0`$ で、$`s_0 = 1`$ なので列 0 に辺が無い。よって最後の列を消して、$`(1)[2] = ()`$ である。$`N`$ によらず、$`(1)[N] = ()`$ である。

**通る分岐.** (0)。

**例 2（$`(1, 2, 3)[2]`$）.** 根の層で、ブロックの最初の列が根の列より左の親を使う例である。

**通る分岐.** (2-3-2)：層 0 の列 2、3。

1. **もとの山.** 表の読み方は §3 の例と同じである。

   | 行 | 列 0 | 列 1 | 列 2 |
   |---|---|---|---|
   | $`2`$ | | $`1 \leftarrow (0, 1)`$ | $`1 \leftarrow (1, 1)`$ |
   | $`1`$ | $`1`$ | $`2`$ | $`3`$ |

2. **根.** 最後の列は $`x = 2`$ で、$`v_1(2) = 3 = v(1, 1) + 1`$ である。よって根は $`(z, d) = (1, 1)`$、$`K = \mathrm{lay}(2) = 0`$ である。$`L = 1`$、$`W = 2 + 2 \cdot 1 = 4`$ で、列 2、3 はどちらも $`j = 0`$ である。列 2 は $`\sigma = 2`$、$`b = 0`$、列 3 は $`\sigma = 2`$、$`b = 1`$ である。

3. **山を写す.** $`s' = (1, 2, 2)`$ で、$`M(s')`$ の列 2 は行 1 に値 2、行 2 に値 $`1 \leftarrow (0, 1)`$ を持つ（$`\mathrm{next}(2, 1) = (1, 1)`$ は値が 2 で $`0 \lt v \lt 2`$ を満たさないので退けられ、次の $`(0, 1)`$ が親になる）。$`\Gamma = \{2, 1\}`$ である。列 2 の marker は phantom $`(2, 0)`$ だけである。$`(2, 1)`$ の親 $`(0, 1)`$ は列 $`z = 1`$ を跳び越えるので marker でない。
   - 列 2（$`c = x`$）：$`M(s')`$ の列 2 のまま。辺 $`1 \to 2`$ の親は $`\nu = (0, 1)`$ で、$`\mathrm{col}(\nu) = 0 \lt z`$ なので (2-3-2) である。

### 1-Y の展開との対応

§3 の「1-Y の山との対応」で、ω-Y の辺と 1-Y の辺を同じものと見る。すると、展開の言葉は次のように対応する。1-Y の記号は 1-Y 版 §3〜§6 のものである。同じ記号（$`z`$、$`K`$、$`L`$、$`W`$、ブロック、$`\sigma`$、$`b`$、$`m_i`$）は同じ意味である。

| 1-Y | ω-Y |
|---|---|
| 列 $`c`$ の層 $`k`$、行 $`r`$ から $`r + 1`$ への辺 | 列 $`c`$ の層 $`k`$ の辺のうち、下から $`r + 1`$ 本目 |
| 高さ $`h_k(c)`$ | 列 $`c`$ の層 $`k`$ の辺の数 |
| 親 $`\mathrm{par}_{k,r}(c)`$ | その辺の親の列 |
| 悪い根の列 $`z`$ と層 $`K`$ | 根の列 $`z`$ と根の層 $`K`$ |
| 悪い根の行 $`d`$ | 列 $`z`$ で根より下にある層 $`K`$ の辺の数（ω-Y の根の行 $`d`$ とは別） |
| 列 $`x`$（$`i = 1`$、$`j = 0`$） | $`M(s')`$ の列 $`x`$（$`b = 0`$） |
| 列 $`z + i L + j \gt x`$ | 列 $`\sigma`$ の marker から (T)、(C)、(F) で作る列 $`\sigma + bL`$ |
| 層 $`k \lt K`$ で、$`\sigma`$ が $`z`$ の上にある | $`F_k(c) \ne \emptyset`$ |

番号が同じ枝は、次のように同じことをする。最小の例は、その枝を通る式（$`N = 2`$）のうち、調べた範囲で辞書式順序が最小のものである。

| 枝 | 1-Y でしていること | ω-Y でしていること | 最小の例 |
|---|---|---|---|
| (0) | 悪い根が無い。最後の列を消す | 根が無い。最後の列を消す | $`(1)`$ |
| (1-1)、(2-1)、(3-1) | もとのまま | 列 $`\lt x`$ はもとのまま | |
| (1-2) | 層 $`\gt K`$。列 $`z + j`$ を $`i`$ 回ずらして写す | 層 $`\gt K`$。列 $`x`$ は減一の山、ほかは同じ行に写す | $`(1, 3, 2)`$ |
| (2-2) | 層 $`K`$、$`j \ge 1`$。ずらして写す | 層 $`K`$、$`j \ge 1`$。同じ行に写す | $`(1, 2, 2)`$ |
| (2-3-1) | 層 $`K`$、$`j = 0`$、行 $`\lt d`$。$`x`$ の親を $`i - 1`$ 回ずらす | 層 $`K`$、$`j = 0`$。$`\mathrm{col}(\nu) \ge z`$ で、親を $`b = i - 1`$ 回ずらす | $`(1, 2, 4)`$ |
| (2-3-2) | 層 $`K`$、$`j = 0`$、行 $`\ge d`$。$`z`$ の親をそのまま使う | 層 $`K`$、$`j = 0`$。$`\mathrm{col}(\nu) \lt z`$ で、親をそのまま使う | $`(1, 2, 3)`$ |
| (3-2-1-1) | 層 $`\lt K`$、$`z`$ の上、行 $`\lt f`$。ずらして写す | 層 $`\lt K`$、$`F_\ell(c) \ne \emptyset`$。(T) の辺 | $`(1, 3, 2, 5)`$ |
| (3-2-1-2) | 行 $`f`$ から $`b e`$ 行伸ばす。親は $`\mathrm{par}_{k,f}(\sigma) + b L`$ | (F) の $`i = 0`$ の辺。親は列 $`m_b(\mathrm{col}(p))`$ の $`q`$ | $`(1, 3)`$ |
| (3-2-1-3) | 行 $`\ge f + b e`$。行を $`b e`$ 上げて写す | (C) の辺で、行が上がり、層は同じ | $`(1, 3)`$ |
| (3-2-2) | 層 $`\lt K`$、$`z`$ の上に無い。ずらして写す | 層 $`\lt K`$、$`F_\ell(c) = \emptyset`$。同じ行に写す | $`(1, 3, 4, 2, 5, 6, 5)`$ |
| (4-1) | 無い | (F) の $`i \ge 1`$ の辺 | $`(1, 4)`$ |
| (4-2) | 無い | (C) の辺で、層が源の辺と違う | $`(1, 4)`$ |
| (4-3) | 無い | (1)〜(3)、(4-1)、(4-2) のどれでもない | $`(1, 3, 10)`$ |

1-Y の (3-2-1-2) の「親は 1 本の列」は、weak magma の「すき間の節点の親はみな 1 本の列 $`m_b(\mathrm{col}(p))`$ にある」（§5）に当たる。1-Y の (3-2-1-1) と (3-2-2) は、どちらも行を変えずにずらして写す。ω-Y ではどちらも同じ行に写すことになり、違いは $`F_\ell(c)`$ が空かどうかだけである。

**確かめた範囲（1-Y との比べ合わせ）.** 次のことを計算機で確かめた（2026-09-26）。証明ではなく、Lean でも示していない。

- §3 と同じ 40850 個の式の、$`N = 1, 2, 3`$ の展開 122550 回のうち、$`(1, 4)[2]`$、$`(1, 4)[3]`$ 以外の 122548 回で、ω-Y と 1-Y の値が同じだった。このとき $`s[N]`$ の山も、§3 の対応で、1-Y の写した山（1-Y 版 §6 の手順 1）と同じ値と親を持ち、辺の層は 1-Y の層に等しかった。列 $`x`$ 以上の辺（約 433 万本）のすべてで、分岐の木の番号が 1-Y の枝の番号と一致した。(4) の枝は現れなかった。
- $`(1, 4)[2]`$、$`(1, 4)[3]`$ では値が違う（ω-Y は $`(1, 3, 10)`$、$`(1, 3, 10, 37)`$、1-Y は $`(1, 3, 9)`$、$`(1, 3, 9, 27)`$）。どちらも (4-1) と (4-2) を通る。
- ω-Y の展開で同じ種から届く長さ 5 以下の式 3542 個（展開 10626 回）でも、値が 1-Y と違うのは $`(1, 4)[2]`$、$`(1, 4)[3]`$ だけだった。長さ 6 以下では、展開 546090 回から無作為に選んだ 30000 回で、違いは無かった。ただし $`(1, 3, 10) = (1, 4)[2]`$ のように 1-Y では届かない式では、§3 の最後のように層がずれることがあり、(4-3) を通る展開が 957 回あった。その値は、1-Y の規則で計算した値と同じだった。
- 山 $`M(s)`$ の値と親が 1-Y と同じ式では、値が 1-Y と違う展開は、(4-1) を通る展開とちょうど一致した（上の範囲と、ω-Y で種 $`(1, 5)`$ から届く長さ 4 以下の式で調べた）。(4-1) と (4-2) は、$`K \ge 2`$ のときにだけ現れた。
- 1-Y で種 $`(1, 5)`$ から届く長さ 4 以下の式 532 個（展開 1596 回）では、378 回で値が違い、番号の対応も成り立たない。これらの山には $`\omega^2`$ 以上の行がある。

最小の例は、ω-Y の種から展開と接頭辞を取って届く式を辞書式順序の順にたどって探した（長さ 8 以下、値 12 以下で $`(1, 3, 4, 2, 5, 6, 5)`$ まで。(4) の枝は長さ 5 以下、値 40 以下で $`(1, 4)`$ まで）。(0)〜(3) の枝の最小の例は、1-Y 版と同じである。

**(4) が 1-Y に無い理由.** 1-Y の (3-2-1) は、根より下の層 $`k`$ ごとに別々に、列を行 $`f`$ から $`b e`$ 行伸ばす。伸ばした行も上げた行も、層 $`k`$ の中にある。ω-Y の (F) は、marker $`\mu = (\sigma, a)`$ ごとに、行 $`a`$ から $`g_b(a)`$ までをまとめて埋める。$`\delta'(q) \ge 1`$ なら、行 $`e_q + \omega^{i}`$（$`i \ge 1`$）の節点を置く。この節点は $`q`$ より上の層にある（(4-1)）。(C) は $`g_b(a)`$ から始まるので、$`\mathrm{lay}(g_b(a))`$ が源の辺の層より大きいと、写した辺は上の層へ移る（(4-2)）。どちらも、$`a`$ と $`g_b(a)`$ の間に層の境目があるときに起きる。1-Y の枝にはこの形が無い。調べた範囲では、(4-3) を通る展開は、どれも $`M(s)`$ の辺の層が 1-Y の層からずれた式（§3 の最後）の展開だった。層がずれた式では、(1)〜(3) の番号も 1-Y の枝と違うことがある。例えば §6 の $`(1, 3, 10)[2]`$ で、列 3 の行 $`\omega`$ への辺は、ω-Y では (2-3-1)、1-Y では (3-2-1-1) である。

**式の確かめ.** このノートの §3、§4 の式をそのまま写した Python のプログラムを書き、参照実装の展開と比べた（2026-09-27）。種 $`(1, 2)`$、$`(1, 3)`$、$`(1, 4)`$、$`(1, 5)`$ から、展開（$`N = 0, 1, 2, 3`$。$`N = 0`$ は最後の列を消すので、接頭辞も届く）をくり返して届く長さ 5 以下の式 101369 個について、$`N = 0, 1, 2, 3`$ の展開 405476 回のすべてで、結果が一致した。手順 1 の $`g_b(a)`$ の集合はいつも空でなく、1 つの列に同じ行の節点が 2 つ置かれることも無かった。分岐の木の番号も、2026-09-26 の比べ合わせで使った番号付けのプログラムの番号と、列 $`x`$ 以上の辺 30052039 本のすべてで一致した。$`M(s')`$ の列 $`x`$ の層 $`\lt K`$ の辺が $`M(s)`$ の列 $`x`$ の一番上の辺より下にあること（§4 の枝 (3-2)）も、この範囲のすべての展開で成り立った。長さ 6 の範囲は、参照実装で式を集めるだけで 60 秒を超えるので調べていない。

## 5. weak magma と公式の ω-Y

公式の ω-Y は、Naruyoko 氏のプログラムの `expand` で定義される（[notes/00-survey.md](../notes/00-survey.md) §1.2）。§4 の (F) の規則を **weak magma** の規則と呼ぶ。weak-magma ω-Y は、§4 の展開による ω-Y である。これは公式の ω-Y と一致しない。公式の展開で $`(1, 3)`$、$`(1, 4)`$、$`(1, 5)`$ から、展開と接頭辞を取ることをくり返して届く式 3001 個について、$`N = 1, 2, 3`$ の 9003 回の展開のうち、480 回で結果が違う（notes/00-survey.md §1.6）。

[notes/02-feasibility.md](../notes/02-feasibility.md) §2 によると、違うのはすき間の節点の親の選び方だけである。

- weak：すき間の節点の親 $`q`$ は、みな 1 本の列 $`m_b(\mathrm{col}(p))`$ にある。$`p = \widetilde{\mathrm{par}}(\mu)`$ は marker $`\mu`$ の親である。
- 公式：すき間の行ごとに、根の列の節点を 1 つ選ぶ（選び方は notes/02-feasibility.md §2.2）。$`M(s')`$ の列 $`\sigma`$ で、選んだ節点と同じ行にある節点を $`u`$ とする。$`\sigma' := \mathrm{col}(\tilde\lambda(u))`$ とする（$`u`$ が最下の節点なら $`\tilde\lambda(u) = (\sigma - 1, 0)`$ で $`\sigma' = \sigma - 1`$）。すき間の節点の親は、列 $`m_b(\sigma')`$ にある。

**例.** $`(1, 3, 3)[2]`$ の列 4 の行 2 の節点（すき間の節点）の親は、weak では $`(2, 1)`$（値 2）、公式では $`(3, 1)`$（値 5）である。列 4 の最下の値は、weak では $`2 + 2 = 4`$、公式では $`2 + 5 = 7`$ である。全体は weak $`(1, 3, 2, 5, 4, 9)`$、公式 $`(1, 3, 2, 5, 7, 12)`$ である（公式の値は notes/02-feasibility.md §2.3 のもので、Lean では計算していない）。

notes/02-feasibility.md は最下の行を 0 と数える。このノートの行 $`1 + \delta`$ を $`\delta`$ と書く。同ノートの「$`k \leftarrow c_j@h`$」は、行 $`k`$ の節点で、左の脚が列 $`j`$ の行 $`h`$ の節点であることを表す。例えば同ノートの「$`1 \leftarrow c_2@0`$」は、このノートの「行 2、左の脚 $`(2, 1)`$」である。

公式の ω-Y の停止性は、このリポジトリの定理ではない。公式の ω-Y は [koteitan/wy-wo-por](https://github.com/koteitan/wy-wo-por) で扱う。

**「no extraction」について.** Phyrion 氏はこの変種を「weak magma、no extraction」と呼ぶ。1-Y 数列の証明には、抽出（Extraction）という段がある。ω-Y の定義には、それに当たる段が無い（notes/00-survey.md §3.5 の表）。行が順序数の 1 つの山だけを使う。ω-Y での extraction の規則の正確な意味は、確かめていない（notes/00-survey.md §1.5）。

## 7. 1 段の展開と最終定理

**定義（1 段の展開）.** $`t`$ が $`s`$ の自明でない 1 段の展開であるとは、ある $`N \in \mathbb N`$ で $`s[N] = t`$ で、$`t \ne s`$ であることをいう。これを $`t \prec s`$ と書く。

- 空の式は、展開しても空のままである。だから空の式から 1 段の展開は無い。空でない式 $`s`$ では $`s[N] \ne s`$ なので、$`t \prec s`$ は「$`s \ne ()`$ かつ、ある $`N`$ で $`t = s[N]`$」と同じである。
- 1 段の展開は辞書式順序を下げる。しかし辞書式順序は整礎でないので、これだけでは停止は出ない。
- 展開はどの式でも定義される（§4 の手順 1 が止まらずに終わる）。これは Lean で示してある。

**定義（届く）.** $`s = t_0, t_1, \ldots, t_j = t`$（$`j \in \mathbb N`$）で、各 $`t_{i+1}`$ が $`t_i`$ の展開 $`t_i[N_i]`$（$`N_i \in \mathbb N`$）であるものがあるとき、$`t`$ は $`s`$ から **届く** といい、$`s \to^{*} t`$ と書く。$`j = 0`$ も許すので、$`s`$ は $`s`$ から届く。$`s`$ から届く式を $`s`$ の **子孫** と呼ぶ。

**定義（次元）.** 自然数 $`D`$ が式 $`s`$ の山の **次元** であるとは、$`M(s)`$ のすべての行 $`a`$ で、$`i \gt D`$ なら $`c_i(a) = 0`$ であることをいう。

- $`s`$ の山の次元が $`D`$ なら、$`s[N]`$ の山の次元も $`D`$ である（Lean で示してある）。
- したがって $`D`$ は始めの式ごとに 1 つ選べば、その子孫すべてで使える。$`D`$ は [06](06-combinatorial-layer.md) の鍵の長さ $`D + 1`$ を決める。

このリポジトリの最終定理（[README](../README.md)「最終定理 4 つ」）は次のとおりである。

1. 定理 1：1 段の展開の関係 $`\prec`$ は整礎である。
2. 定理 2：種から届く式の集合は、辞書式順序で整列する。
3. 定理 3：どの式でも、その子孫の集合は、辞書式順序で整列する。
4. 定理 4：コピーの回数をどう選んでも、展開を続けると空の式に着く。

定理 2〜4 は定理 1 から組合せの議論だけで出る。定理 1 の証明が [06](06-combinatorial-layer.md) 以降の話題である。
